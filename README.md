# Delivery Van

Plan your route, deliver the parcels. Play solo, live or async.

Play it at [poeticmatter.github.io/DeliveryVan](https://poeticmatter.github.io/DeliveryVan/). Part of the [game lab](https://poeticmatter.github.io/game-lab/), built from [poeticmatter/game-template](https://github.com/poeticmatter/game-template).

- **Game id:** `van` (Supabase table `van_games` in the shared `game-lab` project)
- **Modes:** solo, live (PeerJS) and async (Supabase)

## Commands

```bash
npm run dev      # http://localhost:3000
npm run lint     # tsc --noEmit
npm run build
npm run deploy   # build and publish to GitHub Pages (gh-pages branch)
```
